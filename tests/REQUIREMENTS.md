## Limits of the evidence

These are agent skills with deterministic supporting tools. Interviews, research,
atomic decomposition, conflict resolution, actual human review, ontology value
semantics, and faithful tailoring are specified agent responsibilities; passing
software tests is not proof of factual truth. The README and skill report those
limits explicitly. No claim is made that every agent model was launched, that
DOCX was visually checked in every viewer, or that this repository was published
to a remote service. A hosted Git URL can replace the tested local installation
source without changing the skill package.
